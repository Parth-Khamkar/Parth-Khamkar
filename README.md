### 📊 Featured Projects

**[Retail Sales Performance Dashboard](https://github.com/Parth-Khamkar/Retail-sales-dashboard)**
Interactive Power BI dashboard analyzing sales across regions, products, and time periods. Wrote SQL queries to extract, join, and aggregate data, and designed DAX measures for growth, margin, and sales-target KPIs.
`Power BI` `SQL` `Excel` `DAX`

**[Customer Churn Analytics Dashboard](https://github.com/Parth-Khamkar/Churn-Dashboard)**
Analyzed a customer churn dataset with Python (Pandas, NumPy) to identify key drivers of retention and attrition. Built an interactive Tableau dashboard presenting churn trends and risk indicators.
`Python` `Tableau` `SQL` `EDA`

**[Market Trend Analysis & Forecasting](https://github.com/Parth-Khamkar/market-trend-analysis)**
Analyzed 3 years of daily data across 8 market sectors, using SQL (window functions, CTEs) for trend and anomaly detection and a Python (scikit-learn) regression model to produce 90-day forecasts with 95% confidence intervals, ranking sectors by forecast growth.
`Python` `scikit-learn` `SQL` `Forecasting`

**[OpenCV-Based Home Automation with Accident Detection](https://github.com/Parth-Khamkar/OpenCV-Face-Recognition)**
This project consists of multiple detection systems using various libraries and models. It includes face detection using face_recognition and OpenCV, fall detection using a YOLO model, fire detection with a trained model, pose detection using MediaPipe, object tracking with YOLO, and gesture detection using MediaPipe. Each system processes real-time data from a webcam or video files to detect specific events or objects.
`Python` `OpenCV` `MediaPipe` `YOLO` `face_recognition`
